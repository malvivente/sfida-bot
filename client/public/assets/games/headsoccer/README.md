# Head Soccer — Custom Sprites Guide

Questa cartella (`client/public/assets/games/headsoccer/`) contiene tutti gli sprite utilizzati dal gioco **Head Soccer**.
Puoi sostituire qualsiasi file mantenendo lo stesso nome (oppure aggiornarli con versioni più dettagliate). Il motore del gioco li ridimensiona automaticamente sulle hitbox fisiche del canvas (`800x450`).

## Elenco dei file e dimensioni consigliate

| File | Dimensione Consigliata | Descrizione |
| :--- | :--- | :--- |
| `player_a_head.svg` | `128x128` px | Testa del Giocatore 1 (Sinistra, rivolto a destra) |
| `player_b_head.svg` | `128x128` px | Testa del Giocatore 2 (Destra, rivolto a sinistra) |
| `shoe_a.svg` | `96x64` px | Scarpino del Giocatore 1 (punta rivolta a destra) |
| `shoe_b.svg` | `96x64` px | Scarpino del Giocatore 2 (punta rivolta a sinistra) |
| `ball.svg` | `96x96` px | Pallone da calcio standard (centrato, trasparente attorno) |
| `ball_super.svg` | `128x128` px | Pallone infuocato durante il **Super Shot** |
| `goal_left.svg` | `80x160` px | Porta sinistra vista di profilo |
| `goal_right.svg` | `80x160` px | Porta destra vista di profilo |
| `pitch_bg.svg` | `800x450` px | Sfondo dello stadio + campo in erba (linea del terreno a `Y = 390`) |
| `card_headsoccer.svg` | `200x200` px | Illustrazione usata nella card della Home |
